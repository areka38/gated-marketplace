# GATED Support

Public support tracker:

`https://github.com/areka38/gated-marketplace/issues`

When reporting a problem, include:

- operating system and architecture;
- GATED version;
- AI/MCP client name and version;
- the failing GATED command and sanitized error output.

Do **not** attach proprietary source code, repository secrets, credentials, private keys, `.env` contents, customer data, or private AI conversation content to a public issue.

Security-sensitive reports should not be posted publicly. Until a dedicated security contact channel is published, report only that a private security contact is required and do not include exploit details in the public issue.
